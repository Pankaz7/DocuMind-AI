
# 🤖 DocuMind AI

DocuMind AI is a RAG-based AI system that allows users to query documents like resumes, research papers, and reports.

## 🚀 Features
- Ask questions from any document
- Context-aware answers using RAG
- FastAPI backend
- FAISS vector search
- Groq LLM integration

## 🛠 Tech Stack
- Python, FastAPI
- LangChain
- FAISS
- Groq API
- HTML, CSS, JavaScript
